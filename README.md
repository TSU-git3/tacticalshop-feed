# tacticalshop-feed

Stock and retail-price feed for Tactical Shop Ukraine (Kiborg / Militex), for HugeProfit.

- File: `stock.xml` (YML format). Link: https://raw.githubusercontent.com/TSU-git3/tacticalshop-feed/main/stock.xml
- vendorCode = supplier article = Код товару on Prom. price = recommended retail. quantity_in_stock = supplier stock when known; 0 = out of stock; missing = in stock without a number or made to order (see param «Наявність Prom»).
- Source: MyDrop (KIBORG_drop). Updated by Claude.
